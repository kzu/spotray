Spotray

This machine becomes a speaker

Spotray hosts the official Spotify Web Playback SDK so it appears as a Spotify Connect device. Play, pause, and skip from your phone. This window only streams and shows what is playing.

  1. Welcome
  2. Developer app
  3. Sign in
  4. Device name

You will create a free app on the Spotify Developer site, paste the Client ID back here, sign in once, and name this computer. After that, pick this device in the Connect picker on your phone.

A Spotify Premium account is required to stream.

Get your IDs from the Dashboard

    Obtain an access token

    Spotify issues tokens through a sign-in, not the Dashboard page itself. Click below to open the official Spotify login. After you approve streaming, this app stores a refresh token so the player can stay connected.
